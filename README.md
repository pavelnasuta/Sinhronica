# Синхроника

Mobile-first PWA для спортсменов по синхронному плаванию. Первый этап — дизайн-система и локальная техническая основа: приложение работает без сервера, хранит данные только в браузере и может устанавливаться как PWA.

## Визуальная система

- тёмная тема по умолчанию и светлая альтернатива;
- палитра воды: циан, синий, индиго и фиолетовый; золото — только для достижений;
- локально собранный шрифт Manrope — работает без сети;
- иконки PWA для обычной, Apple Touch и maskable-установки;
- адаптивная оболочка с безопасными отступами и мобильной нижней навигацией.

Полная спецификация токенов и правил компонентов: [`DESIGN.md`](DESIGN.md).

## Данные и приватность

Данные хранятся в `localStorage` этого браузера и профиля. Они не отправляются на сервер и не синхронизируются между устройствами. Не используйте приложение как единственное место хранения важных спортивных записей до появления механизма резервного копирования.

## Локальный запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

## Проверка перед публикацией

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

## Публикация

Проект публикуется через GitHub Pages. Для репозиторного пути в production-сборке задаётся `VITE_BASE_PATH` с именем репозитория.
